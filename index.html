Get the grabber

A Python script that logs into Garmin Connect, fetches only runs it hasn't seen before, keeps the original GPX files, and writes one runs.json for step 2.

View on GitHub

Set up once

python3 -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\activate pip install --upgrade garminconnect curl_cffi ua-generator

Run whenever you want an update

python garmin_grab.py
  • Needs Python 3.12 or later. First run asks for your Garmin email, password and MFA code; tokens are then saved in ~/.garminconnect.
  • The first pass over ten years takes roughly 1–2 hours because it pauses between downloads. Ctrl-C is safe; the next run resumes.
  • Later runs stop as soon as they reach activities they already know, so they take seconds.
  • Options: --since 2016-01-01 --rebuild (no network) --full (rescan everything).

Resting heart rate

        
Daily value from your watch, with the 30-day median. A falling resting heart rate usually means rising aerobic fitness. A sudden rise of 5 bpm or more often means fatigue, illness or poor sleep. The filters don't apply here.

How to read this

      
Pace at the same heart rate is the most reliable fitness signal for steady running. A chest strap makes it trustworthy; wrist readings are noisier. Pick a band you hit on most easy runs.

      
Best efforts come from any stretch of any run, so a year without races shows training efforts and understates your real level. Races give the cleanest points.

      
Hills are corrected with Minetti's energy-cost curve over 100 m windows. Heat raises heart rate at a given pace; use the month filter to compare like with like.

      
Trend is the Theil–Sen slope of the yearly medians, which ignores single odd years. Years with fewer than 5 qualifying runs are left out of it.

      
Aerobic decoupling only uses steady runs: the hill-adjusted pace of 5-minute blocks must stay within 10% of their average, so interval sessions drop out. Heat and dehydration raise it, so compare similar seasons.

      
Training load is Banister's TRIMP. Treadmill runs without a heart-rate stream use their average heart rate. Runs with no heart rate at all add nothing, which understates the load. Max and resting heart rate set the zones and the load; a wrong max shifts every zone, so enter a measured one if you have it.

      
Zones come from the heart-rate stream. Runs without one fall back to Garmin's own zone times, which use the zones set in Garmin Connect.
